# Sistema de Gestión para el Taller Mecánico Autosemec

Este proyecto documenta el análisis, diseño y negociación de una solución tecnológica para Autosemec, el taller mecánico 
de don Rony Payes. Incluye la recolección de requisitos, el análisis del flujo de negocio y la propuesta de un sistema de 
gestión estructurado en fases (expediente digital, control de repuestos, presupuestos y agenda), consensuado mediante un 
debate técnico enfocado en la resolución de conflictos y la comunicación asertiva.
